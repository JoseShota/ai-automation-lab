# Datos

Regla: **solo datos públicos o sintéticos**. Nunca datos reales de personas, contribuyentes ni de la operación interna de una institución.

Para cada conjunto de datos, agrega una línea aquí:

| Archivo | Fuente | Licencia o tipo | Fecha de descarga |
| --- | --- | --- | --- |
| | | | |

Fuentes sugeridas:
- Portal de datos abiertos de la Ciudad de México.
- Informes trimestrales y cuenta pública publicados por la Secretaría de Administración y Finanzas.
- Normativa fiscal publicada (por ejemplo, el Código Fiscal de la Ciudad de México).

Las carpetas `data/private/` y `data/raw/` están en `.gitignore` por si necesitas trabajar con archivos que no deben subirse.
