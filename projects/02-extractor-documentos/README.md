# 02 · Extractor de documentos

**Estado:** pendiente (semana 3)

## Problema
Facturas, oficios y comprobantes fiscales se capturan a mano, con errores y mucho tiempo invertido.

## Solución propuesta
PDF o imagen → la IA extrae los campos a un JSON con estructura fija → validaciones automáticas (sumas, RFC, fechas) → los documentos con errores pasan a revisión humana.
