# 01 · Clasificador de solicitudes

**Estado:** pendiente (semanas 1–2)

## Problema
Las solicitudes llegan por correo o formulario sin orden; alguien las lee una por una y las reparte a mano al área correspondiente.

## Solución propuesta
Formulario o correo → la IA clasifica la solicitud (tema, urgencia, área) y extrae los datos clave → se registra en una hoja o base de datos → los casos dudosos pasan a revisión humana.
