# 04 · Agente de consulta normativa

**Estado:** pendiente (semana 5)

## Problema
Las mismas dudas sobre reglas, lineamientos y trámites se responden una y otra vez, y encontrar el artículo exacto toma tiempo.

## Solución propuesta
Documentos normativos públicos → se dividen e indexan (embeddings) → el agente busca los fragmentos relevantes y responde **citando la fuente** → si no encuentra respaldo, lo dice.
