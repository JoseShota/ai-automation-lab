# 03 · Reporte automático de finanzas públicas

**Estado:** pendiente (semana 4)

## Problema
Los informes periódicos se arman copiando tablas de distintas fuentes y redactando resúmenes a mano.

## Solución propuesta
Ejecución programada → descarga de datos abiertos → limpieza y cálculo en Python → la IA redacta un resumen ejecutivo → el reporte se envía por correo o se publica.
